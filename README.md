# 化學品法規速查表

輸入化學品與數量（例如：甲苯 2000 L），工具會對照台灣 16 部化學品相關法規，列出適用的義務、管制量倍數與合計指數，並可以匯出 Excel。

**線上使用**：開啟 GitHub Pages 網址即可，不需要安裝任何程式。

## 涵蓋法規
職業安全衛生法、危害性化學品標示及通識規則、有機溶劑中毒預防規則、勞工作業場所容許暴露標準、道路交通安全規則（第 84 條）、事業廢棄物貯存清除處理方法及設施標準、公共危險物品及可燃性高壓氣體製造儲存處理場所設置標準暨安全管理辦法、危害性化學品評估及分級管理辦法、勞工作業環境監測實施辦法、職業安全衛生設施規則、優先管理化學品之指定及運作管理辦法、工廠危險物品申報辦法、特定化學物質危害預防標準、毒性及關注化學物質管理法、勞動檢查法（危險性工作場所）、先驅化學品工業原料之種類及申報檢查辦法。

## 資料庫（740 筆）
- 勞工作業場所容許暴露標準 附表一 489 項（含有機溶劑、特定化學物質分類與作業環境監測項目）
- 列管毒性化學物質 附表一全部品項（115.04.27 修正）
- 關注化學物質 19 項
- 26 種常用化學品附 SDS 物性與 GHS 分類

法規資料截至民國 115 年 10 月。

## 主要功能
- 單筆輸入，或從 Excel 貼上清單、匯入盤點表
- 三種檢視：總覽矩陣、依化學品、依法規
- 搜尋、法規篩選、只顯示需辦理
- 匯出 Excel，共 6 張工作表：判定結果、法規矩陣、依法規彙整、合計指數、化學品資料庫、法規來源
- 可自訂化學品資料（存在使用者自己的瀏覽器）

## 檔案
- `index.html`：工具本體
- `chem-data.js`：法規清單資料（法規修正時更新此檔）

## 免責聲明
本工具依法規條文與附表整理，僅供初步判定參考。化學品分類與濃度請以供應商 SDS 為準，實際義務以主管機關解釋為準。
